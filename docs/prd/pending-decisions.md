### 남은 결정 대기 항목
1. 완결성 룰 층의 **금칙 모호어 사전** — PoC에서 초안, F12 회귀로 확정.
2. LLM 층 루브릭 임계치 — F12 회귀로 튜닝.
3. **명확화 왕복 상한 수치** *(v1.4 추가 — 목업 상한과 대칭)*와 상한 도달 시 승격 판정의 기준.
4. **슬롯 `승격` 판정 기준** *(v1.4 신설)* — 무엇을 "요청자가 원리적으로 답할 수 없음"으로 볼 것인가. 남용되면 정제가 무력화되고, 인색하면 데드락이 돌아온다. PoC 세션으로 초안.
5. **게이트 SLA 수치와 근무시간 정의** *(v1.4 신설)*, SLA 초과 자동 백로그의 유예 단계 수.
6. **거절 이의 경로의 운영 주체와 절차** *(v1.4 신설)* — 팀 리드 단독 판단 vs. 주간 리뷰 안건.
7. 목업 반복 상한(2 vs. 3)과 초과 시 에스컬레이션 경로.
8. 세션당 토큰·목업 폭주 방지 상한 수치 + 평가 예산.
9. SSO(SAML vs. OIDC)와 매직 링크 병행 정책 / 목업 서명 URL 만료 기본값.
10. **Phase 0 중단·전환 기준의 수치화** *(v1.4 신설)* — 개발자 검토 통과율 X%, 세션 완주율 Y%, "요청자 해소 불가" 비율의 재설계 임계치 Z%.
11. **Phase 1 중단 기준 수치** *(v1.4 신설)* — 정책 발효 +4주 시점의 우회율·이탈율 상한.
12. **우회 집계의 "기능 요청 이슈" 필터 정의** *(v1.4 신설)* — 어떤 이슈 타입/라벨을 분모에 넣을 것인가. 잘못 잡으면 지표가 통째로 무의미해진다.
13. F13 L2 도입 임계치 수치(주간 세션 수 N, 축적 라벨 수 M, judge-인간 일치율 기준) — L1 운영 데이터로 확정.
14. 백로그 재부상 트리거 수치(유사 요청 누적 N회, 정기 리뷰 주기).
15. **다중 스테이크홀더 상충 해소의 정식 모델** — Phase 1 최소 모델 운영 후 확정.
16. **과거 거절 이력의 유효기간** *(v1.4 신설)* — 언제까지 참고 정보로 제시할 것인가.
17. PoC Exit 기준 / 하네스 인증 방식·실행 환경 — 보안 검토 후.
18. Agents API 조기 파일럿 착수 조건(Preview 변경 모니터링 체계).
19. **첨부 상한 3종** *(v1.5 신설)* — 파일당 크기, 세션당 추출 텍스트 총량, 세션당 첨부 개수. 총량 초과는 업로드 시점 거부이므로(F1-Attach) 수치가 곧 요청자가 마주치는 벽이다. 8번(세션당 토큰 폭주 방지 상한)과 함께 정한다.
20. **세션·첨부 보존 기간** *(v1.5 신설)* — 첨부 원본을 불변 보관하기로 한 이상 보존 기간이 곧 노출 기간이다. 요청자에게 하는 저장 고지의 전제이기도 하다(요청자 여정 설계 O-1).
21. **장문 소스 규율 수치 3종** *(v1.8 신설 — [ADR-0014](../adr/0014-long-source-discipline.md))* — 요청자 발화 길이 상한(기본 10k자), 장문 첨부 압축 목표(기본 6k자), 생성 호출 조립 예산(기본 60k자 = 첨부 개수 상한 × 압축 목표). 기본값 근거는 실측 생성 속도(~72토큰/초)와 300초 봉투(#56)이며, F11 신호(`attachment_condensed`·타임아웃)로 튜닝한다. 19번(첨부 상한 3종)과 함께 정한다.
