# 우회율은 세션 귀속(provenance) 스캔으로 자동 집계한다

생성되는 모든 Linear 이슈에 세션 ID를 기계 판독 가능한 형태(커스텀 필드 또는 규약 라벨)로 남기고, 우회율은 "귀속 없는 기능 요청 이슈 수 / 전체 기능 요청 이슈 수"로 전수 집계한다. 개발자 액션은 0이다.

## Considered Options

v1.3의 개발자 1클릭 자발적 태깅은 폐기 — 우회가 일어나는 상황(그냥 받는 게 빠름)과 성실한 태깅이 누락되는 상황이 정확히 같아서, 지표가 낙관 방향으로 편향되고 그 편향은 실패가 심할수록 커진다. 자발적 태깅은 보조 수단으로만 유지한다.

## Consequences

롤아웃 정책("모든 기능 요청은 PM Jude 경유") 발효 후 우회율은 채택 지표가 아니라 컴플라이언스 지표다. 강제 하의 실패 모드는 우회가 아니라 성의 없는 통과이며 이는 우회율에 잡히지 않으므로, 채택 판단은 선행 지표(중도 이탈율·재사용률·요청자 소요 시간)로 한다.

출처: PRD v1.4 F6, §10.
